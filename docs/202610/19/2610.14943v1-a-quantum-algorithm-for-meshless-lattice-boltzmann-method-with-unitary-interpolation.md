## 摘要
我们提出一种用于移位不可压缩格子玻尔兹曼方法（LBM）的质量加权无网格表述，其迁移步严格酉，并与Carleman嵌入相结合。在传统无网格LBM中，散乱节点集上的半拉格朗日迁移步是一种插值，因而并非酉的；因此对该矩阵进行通用块编码需要与其稀疏度成正比的归一化以及对数数量的辅助量子比特。为克服非酉性，我们转而将插值表示为模拟导数算子的指数exp(a Dx + b Dy)。通过为每个节点赋予其Voronoi质量并应用质量加权相似变换，在施加矩约束以及低波数三角函数微分条件下，使这些导数算子成为反厄米算子，从而使插值变为严格酉的。这种插值酉化除了对其二次项进行重缩放外不改变局部碰撞步，其中相同的权重定义了分布函数的振幅编码。对于准均匀节点集，质量加权对角仍处于单位阶归一化范围内，且随着Carleman截断阶数增大仅轻微退化，从而减轻了块编码的成本。在Taylor-Green涡上的数值实验证实，该方法能够重现完整的无网格LBM，且速度误差随Carleman阶数增加而减小。

## Abstract
We present a mass-weighted meshless formulation for the shifted incompressible lattice Boltzmann method (LBM) whose streaming step is exactly unitary, combining with the Carleman embedding. In traditional meshless LBM, on a scattered node set the semi-Lagrangian streaming step is an interpolation, which is not unitary; a generic block encoding of this matrix therefore requires a normalization proportional to its sparsity and logarithmically many ancillas. To overcome the non-unitarity, we instead express the interpolation as the exponential exp(a Dx + b Dy) of mimetic derivative operators. Endowing each node with its Voronoi mass and applying a mass-weighted similarity transform renders these derivative operators skew-Hermitian by enforcing moment constraints together with low-wave number trigonometric differentiation conditions, so that the interpolation becomes exactly unitary. Such unitarization of interpolation leave the local collision step unchanged up to a rescaling of its quadratic term, where the same weights define the amplitude encoding of the distribution functions. For quasi-uniform node sets, the mass-weighting diagonal remains within a unit-order normalization that degrades only mildly as the Carleman truncation order grows, thereby mitigating the cost of block encoding. Numerical experiments on the Taylor Green vortex confirm that the method reproduces the full meshless LBM, with the velocity error decreasing as the Carleman order increases.
