Abstract 

We present a structure-aware construction of quantum BPX preconditioners for Q1 finite element discretizations of constant-coefficient reaction–diffusion equations on the unit cube, including the Poisson equation. Building on existing quantum finite element and finite difference methods, we express the preconditioned operator through explicit one-dimensional maps, tensor products, and norm-preserving interlevel transfers. Symmetric preconditioning gives multilevel coefficients, and its favorable conditioning alone does not ensure efficient recovery of a state in the original finite element nodal basis. We instead use the local L2-orthonormal basis underlying the construction as the output representation of the same finite element function. Its coefficient norm equals the continuous L2 norm. Assuming direct access to the preconditioned right-hand side, we prepare this orthonormal coefficient state with a represented function error at most ε.The expected query complexity is

1arXiv:2610.06987v1 [math.NA] 4 Oct 2026 1 Introduction 

Finite element discretizations of elliptic partial differential equations lead to large sparse linear systems whose conditioning deteriorates under mesh refinement [1]. Multilevel preconditioning addresses this difficulty by combining corrections on a hierarchy of approximation spaces. The classical BPX construction [2] and the subspace-correction framework [3] provide the foundations for such additive multilevel methods. Quantum linear system algorithms prepare states encoding solutions without computing ev-ery coefficient, beginning with the algorithm of Harrow, Hassidim, and Lloyd [4]. Subsequent developments improve the dependence on precision [5] and provide a general framework for matrix transformations through block encodings [6]. For elliptic problems, Cao et al. [7] give a quantum algorithm and circuit construction for the discretized Poisson equation, while Montanaro and Pal-lister [8] analyze finite element algorithms with discretization and output accuracy included in the comparison with classical methods. These works emphasize that input access, matrix conditioning, and the requested output must all enter the complexity analysis. Quantum preconditioning has been studied for general linear systems [9], including fast inver-sion for constructing inverse preconditioners [10]. For multilevel discretizations, a central difficulty is that multiplying separate block encodings of the system matrix and the preconditioner can retain the unfavorable normalization of the original discretization. A spectral bound for the precondi-tioned matrix alone is therefore insufficient. Deiml and Peterseim [11] address this issue for Q1 discretizations of elliptic diffusion problems by constructing the preconditioned gradient through local L2-orthonormal coordinates and multi-level transfers. Their analysis allows variable diffusion tensors and establishes complexity bounds for linear functionals. Jin, Liu, Ma, and Yu [12] develop a related finite difference construction using a commuting identity and Schr¨ odingerization. Together, these works motivate constructing the complete preconditioned operator from its discretization structure. The present work develops this approach for the Q1 discretization of −∆u+cu = f on the unit cube, with constant c ≥ 0. Reaction–diffusion systems also occur as the shifted elliptic subproblems in rational approximations of fractional operators. We examine a BPX factor that combines inverse mass square roots with weights depending on the reaction coefficient. The analysis tracks the dimension, refinement level, and reaction coefficient explicitly, and connects circuit accuracy to the continuous L2 error of the represented finite element function. The choice of output representation is essential. Symmetric BPX preconditioning solves for multilevel coefficients; obtaining a state of the coefficients in the original finite element nodal ba-sis requires a further transformation whose cost is not controlled by the preconditioned condition number alone. We therefore use the local L2-orthonormal basis, already introduced to construct the block encodings, to represent the output solution. This changes the coefficient representation while preserving the finite element function. The Euclidean error of these orthonormal coefficients is exactly the continuous L2 error between the represented functions, so the analysis can address continuous accuracy directly. Our solution-state complexity bound concerns this orthonormal rep-resentation; it does not include an additional conversion to a nodal coefficient state. 2Building on the quantum finite element framework of [11], we focus on the parameters and coefficient representations that determine the quantum cost. That work already provides the un-derlying orthonormal gradient construction and isometric transfers, with a block-encoding normal-ization proportional to dL for unit diffusion. The present contributions refine this framework in the following four respects. 

• Explicit dimension dependence in the quantum error and complexity analysis. We give a finite element L2 error constant of 3, an effective condition-number bound of 12 dL 2 for the BPX system, and a matrix block-encoding normalization of 12 dL . Here d is the spatial dimension, L = log 2(1 /h ) is the number of refinement levels, and h is the finest mesh width; the effective condition number uses only nonzero eigenvalues. These bounds hold uniformly in the reaction coefficient c ≥ 0 and make explicit the dimension dependence left implicit in the BPX condition estimate of [11]. 

• Solution-state preparation under a continuous L2 error requirement. Let u be the exact solution with right-hand side f , and let uqh denote the function represented by the output coefficients in the local L2-orthonormal basis. Assuming direct access to the preconditioned right-hand side, we establish ∥u − uqh∥L2 ≤ ε for a prescribed accuracy 0 < ε ≤ ∥ u∥L2 /2. For fixed ∥f ∥L2 /∥u∥L2 , the query bound has no algebraic inverse-mesh factor, including the cost of converting multilevel coefficients to this orthonormal coefficient state. This complements the linear-functional complexity result in [11, Theorem 6.5]. 

• A structure-aware block encoding of the preconditioned system. Following the ap-proach of [12], we exploit the nested Cartesian grids to express the required maps through explicit one-dimensional matrices and tensor products. Commuting identities move differen-tiation to each coarse level, where the BPX weights balance its scale, and norm-preserving transfers then lift the coefficients to the finest level. This gives a block encoding of the com-plete preconditioned operator with controlled normalization. By specializing the framework of [11] to this tensor structure, we obtain a transparent sequence of encoding steps with explicit normalization factors. 

• A modified BPX factor connecting quantum coefficients to continuous norms.

# 3 Block encoding through local value and gradient coordinates 

We construct the block encoding through Gram factorizations of the mass and stiffness ma-trices, following the strategies in [11, 12]. Local L2-orthonormal coordinates convert function inner products into Euclidean coefficient products and make interlevel transfer isometric. We first con-struct these maps, then combine them with the inverse mass square roots and BPX weights.

# 6 Comparison and concluding discussion 

This article explains quantum BPX preconditioning for Q1 reaction–diffusion discretizations within the framework of [11, 12]. The construction starts from one-dimensional Gram factors, ex-tends them by tensor products, and uses isometric transfers to assemble the multilevel energy map. For Sℓ = ωℓPℓM −1/2 

> ℓ

, the nonzero spectral interval is [1 /L, 12 dL ] and the encoding normalization of AS is 12 dL , uniformly in c ≥ 0. The Poisson problem is obtained at c = 0, and each shifted system in a fractional rational approximation has the same reaction–diffusion structure. Normalizing the one-dimensional value maps before forming tensor products avoids the explicit factor 3 d−1. With the preconditioned right-hand side supplied directly, the inverse and preparation of the multilevel variable state have no algebraic inverse-mesh factor. For the solution state in the local L2-orthonormal basis, the map E introduces the amplification ratio ∥bS ∥2/∥uh∥L2 . For 0 < ε ≤ ∥ u∥L2 /2, this ratio is bounded by 6 ∥f ∥L2 /(5 √3∥u∥L2 ). The resulting bound (4.10) contains no algebraic inverse-mesh factor when ∥f ∥L2 /∥u∥L2 is fixed. Its data dependence is essential; increasing the magnitude of the solution alone does not improve the amplification ratio. With the preconditioned test state also supplied, direct estimation of a bounded L2 functional avoids 32 the solution conversion, requires no restriction on the accuracy relative to the solution norm, and satisfies (4.18). For comparison, a classical tensor sine solve with an assembled load vector takes O(dLN )arithmetic operations, where N = (2 L − 1) d, and returns all nodal coefficients. The quantum bounds count queries to supplied preconditioned-input oracles and matrix encodings, and produce either a normalized local L2-orthonormal coefficient state or a prescribed scalar estimate. The solution-state bound uses this representation of the same finite element function; further conversion to a state in the original nodal basis would require a separate cost analysis. Constructing these oracles, elementary gate costs, and classical readout must therefore be included when comparing complete algorithms.
