## 摘要
在结构化哈密顿量的容错块编码中，支撑几何可以决定 SELECT 的非 Clifford 成本如何随系统规模变化，无论每个支撑上有多少算子作用。我们构造了置换-作用-逆置换电路：由该几何固定的 CSWAP 网络将选定的支撑带到固定目标寄存器，一个共享局域电路在该处作用，然后撤销置换。算子仅在该寄存器上添加一个 $XZ$ 掩码，其成本与系统规模无关，并且一次查询可以混合若干种支撑几何。对于双位点支撑，我们在由位点对换构成的地址控制网络中建立并达到了最小 CSWAP 数量。针对泡利项编译后，这些电路使用 $8\mathrm{S}N+o(N)$ 个 $T$ 门，并需要 $O(\log N)$ 个置换工作量子比特，其中 $N$ 是系统量子比特数，$\mathrm{S}$ 由支撑几何决定；对于最近邻相互作用 $\mathrm{S}=1$，对于全对全配对 $\mathrm{S}=3/2$；两种情况下修正项均为 $O(\log N)$。我们还引入桥接 CSWAP：它在目标作用期间记住其临时 AND 的逻辑值，并从准备好的标签中修复该值，从而使逆 CSWAP 无需重新计算该值即可撤销交换。当修复为 Clifford 时，它以多保留一个工作量子比特为代价，将匹配的正向-逆 CSWAP 对的 $T$ 门数减半。对于海森堡环，随着系统规模增大，完整块编码查询相对于平坦与乘积式泡利行走，将 $T$ 门数降低到原来的约 $1/3$（降低因子趋近于 $3$）。对于五轨道 Anderson 杂质模型，它结合了最近邻与全对全支撑几何，在大浴尺寸下，相对于三个比较器中最便宜者，其降低因子约为 $1.7$；每个比较器均根据其所引用的参考文献中的方法构建。

## Abstract
In fault-tolerant block encodings of structured Hamiltonians, the support geometry can set how the non-Clifford cost of SELECT scales with the system size, however many operators act on each support. We construct permute-act-unpermute circuits: a CSWAP network fixed by this geometry brings a selected support to a fixed target register, a shared local circuit acts there, and the permutation is undone. The operators add only an $XZ$ mask on this register, at a cost independent of the system size, and one query can mix several support geometries. For two-site supports, we establish and attain the minimum CSWAP count within address-controlled networks of site transpositions. Compiled for Pauli terms, these circuits use $8\mathrm{S}N+o(N)$ $T$ gates with $O(\log N)$ permutation work qubits, where $N$ is the number of system qubits and $\mathrm{S}$ is determined by the support geometry, with $\mathrm{S}=1$ for nearest-neighbour interactions and $\mathrm{S}=3/2$ for all-to-all pairs; in both cases the correction is $O(\log N)$. We also introduce a bridged CSWAP, which remembers the logical value of its temporary AND across the target action and repairs it from the prepared labels, so that the inverse CSWAP undoes the exchange without recomputing the value. When the repair is Clifford, it halves the $T$ count of a matched forward-inverse CSWAP pair at the cost of one retained work qubit. For a Heisenberg ring, the complete block-encoding query reduces the $T$ count by a factor approaching $3$ as the system size grows, relative to flat and product-wise Pauli walks. For a five-orbital Anderson impurity model, which combines nearest-neighbour and all-to-all support geometries, the reduction is about $1.7$ at large bath sizes, relative to the cheapest of three comparators, each built from the methods of the references it follows.

# 《Efficient Block Encoding of Structured Hamiltonians by Separating Where and What》论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：在量子奇异值变换（QSVT）等框架下，哈密顿量块编码（block encoding）的非 Clifford 成本（主要为 T 门）会在每次查询中反复付出，因此降低 SELECT 的 T 门数是容错量子模拟的核心问题。
- **问题**：LCU/Prepare–Select 方案中，通用构造（如 unary iteration）把哈密顿量项当作"平坦列表"处理，T 门数随**项数**增长，即随"支撑数 × 算符类数"的乘积增长。
- **观察**：实际哈密顿量具有结构——少数局域算符（场、跃迁、交换、plaquette、密度–密度等）在由**几何**组织的许多支撑上重复出现（最近邻键、格点 plaquette、全对全耦合等）。
- **核心矛盾**：平坦列表对每个作用在支撑上的算符重复选支撑、对每个携带算符的支撑重复写算符，成本是两者的乘积。
- **整体含义**：若把"作用在**何处**（where）"与"作用**何种**算符（what）"分离，则两者成本**相加**而非相乘；且支撑几何决定 T 门随系统规模 N 的标度，而与算符类数无关。

## 2. 方法论

### 2.1 核心思想：permute–act–unpermute

- 将每项写成共轭形式：`H = Σ_{j,b} α_{j,b} Π_j^{-1} P^{(b)}_T Π_j`
  - 地址 `j` 决定**何处**（支撑），标签 `b` 决定**何种**算符；
  - `T` 是固定的目标寄存器（n_T 个系统量子比特），`Π_j` 把选中支撑搬到 `T`。
- SELECT 分解为三步：
  1. **Permute**：由几何固定的 CSWAP 网络把选中支撑送到 `T`；
  2. **Act**：共享局域电路在 `T` 上作用算符（对 Pauli 项仅为 XZ 掩码）；
  3. **Unpermute**：逆置换 `Π_j^{-1}` 恢复系统。
- 关键收益：只有置换触碰全部 N 个系统量子比特，且只依赖地址；新的算符类只改变 target action，成本与 N 无关（显式 XZ 掩码仅给 Prepare 加 `8 n_T` 个 T）。

### 2.2 成本计量与 CSWAP

- 以 **temporary AND opening** 为成本单位：一次 opening 写一个 ancilla 花费 **4 T**，关闭为测量 + Clifford 修正，**零 T**。
- CSWAP 实现：CNOT 存奇偶 → opening 写 `ω = c(q0 ⊕ q1)` → CNOT 交换 → 关闭；每个 CSWAP 一次 opening（4 T）。
- **swap tree**（来自 SelectSwap lookup）：在 M 个叶子上用 **M − 1** 个 CSWAP、⌈log₂M⌉ 层把被选中叶子送到根（根即叶 0）。

### 2.3 支撑几何决定置换成本

- 定义 **χ**：使"没有支撑同时含两个同组位点"的最少分组数（强色数）。
- 两体支撑的 CSWAP 数：`⌈N + χ/2 − 3⌉`，并**证明这是地址控制位点对换网络的最小值**（附录 A 2b，用完整多部图 + 激活/分裂计数论证）。
- CSWAP 密度 `S`：
  - 最近邻/有限程键（χ 有界，如 χ=2）：**S = 1**；
  - 全对全配对（χ = N）：**S = 3/2**。
- 三体全支撑：S = 3/2，但比 3N/2 多出约 √N 项；四体及以上全支撑的 leading order 仍开放。

### 2.4 Bridged CSWAP（桥接）

- 逆 CSWAP 只需 work bit 的**值**，不需重新计算。
- 目标作用使配对奇偶改变 δ，则逆门需要 `ω' = ω ⊕ cδ`，可用 `X^{cδ}` **修复**而非重开。
- 当修复为 Clifford（如 Pauli 目标的 X 掩码、对角作用 δ=0）时，配对成本从 2 次 opening 降为 1 次，代价是跨作用保留一个 work bit。
- 网络内 δ_λ(j,b) 为落在 λ 两位上的 X 掩码奇偶；修复谓词 `c_λ δ_λ` 构成 repair word，可由共享产品摊销。
- 与 Ref. [16] 的 adjacent-AND merge 等价，但不要求两次 opening 相邻。

### 2.5 资源公式

- 闭合配对：`T_sel^cl = 8SN + 4N_pred + o(N)`，`A_Π = N_pred + 1 = O(log N)`。
- 混合桥接：`T_sel = 8SN − 4(N_br − N_rep) + 4N_pred + o(N)`，`A_peak = N_br + N_rep + N_pred + O(1)`（T 门与宽度的权衡）。
- 若所有修复为 Clifford，leading 项可减半为 4SN，代价是 SN 个 live work bit。
- 地址控制（control generator G）：非线性乘积 N_pred = O(log N)；地址 toggle 用冻结的进位/借位链切换同一地址寄存器（图 13）。

## 6. 主要结论与发现

- **Heisenberg 环**：完整查询约 **8N** T 门，相比 flat/product-wise Pauli walk（24N）**降低近 3 倍**，且 peak width 更小；leading 因子 3 源于平坦 walk 每项付 4 T（每站点 6 项），而两个 swap tree 每站点付 8 T，与算符类数无关。
- **AIM**：完整查询约 **12N**（leading），在大浴尺寸下相比最便宜比较器（40 n_imp n_bath）**降低约 1.7 倍（约 40% fewer）**，peak ancilla 相当；在 (5,100) 与 (5,1000) 时优于所有对比构造。
- **理论结果**：
  - 两体支撑达到地址控制位点对换网络的**最小 CSWAP 数**；
  - 全对全配对与平面波化学构造（Ref. [16]）同为 12N leading，但适用于任意 pair 上的 Pauli 算符；
  - 相比无 ancilla 的二次费米子电路（Ref. [26]）**T 门少 4 倍**；
  - 对三体全支撑，最小数超出 3N/2 约 √N/2。
- **成本分离结论**：SELECT 的 leading 成本与耦合系数的数量和价值无关（系数只进入 Prepare）；几何（连通性）决定标度。

## 7. 优点

- **概念清晰**：把"where/what"分离，使成本相加而非相乘，是通用且可复用的编译原则。
- **几何驱动的成本律**：用 CSWAP 密度 S 统一刻画（最近邻 S=1、全对全 S=3/2），并给出匹配的下界证明。
- **bridged CSWAP 技巧**：利用目标作用对 work bit 输入的确定性改变做"修复"而非重算，Clifford 修复下配对成本减半，思路可推广到任何"输入被中间操作改变"的临时值复用。
- **多几何可混合**：不同支撑几何族可在一次查询中顺序组合，非活跃族自动退化为恒等，成本相加（AIM 实例）。
- **费米子友好**：受控费米子对换的 Jordan–Wigner 符号仅需 CZ，T 门与 ancilla 数不变；全对全网络用 parity rule 把符号降到 O(N) 个 Clifford 门。
- **工程细节完整**：给出地址 toggle、control generator、repair word、Prepare 接口与完整查询装配（附录 C、D），并与多个已有构造在统一口径下比较。

## 8. 不足与局限

- **bridging 的实际收益有限**：在两个案例中只影响次leading项，leading 收益仍来自置换的复用；bridging 需要保留 live work bit，存在 T 门与宽度的权衡，未必在所有场景划算。
- **理论空白**：
