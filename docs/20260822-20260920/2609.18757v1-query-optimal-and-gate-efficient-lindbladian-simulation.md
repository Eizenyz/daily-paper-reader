## 摘要
我们给出一种 Lindbladian 模拟的量子算法：给定哈密顿量 H 的块编码以及堆叠跳跃算子 B=∑_{k=1}^m |k⟩⊗L_k 的投影酉编码，其归一化因子分别为 α_H 和 α_B。对于演化时间 t，令 τ=(α_H+α_B^2)t。该算法使用 O(τ + log(1/ε) / log(e + log(1/ε)/τ)) 次 oracle 查询，将演化信道逼近到菱形范数误差 ε，匹配哈密顿量模拟的查询下界。额外的单量子比特门和双量子比特门数量在至多多对数因子的意义下与查询复杂度成线性关系。查询复杂度和门复杂度界可推广到在相干时间索引 oracle 访问下的 Lipschitz 连续含时 Lindbladian。我们的构造使用一个单查询转换器，在给定催化剂时实现短时演化的有理逼近的乘积。我们通过利用不同 Kraus 标签序列之间的正交性，来界定省略催化剂所导致的误差。门实现结合了压缩的 Kraus 标签表示（仅存储非零标签的位置和值）与 Chen 等人的旋转分解。

## Abstract
We give a quantum algorithm for Lindbladian simulation given a block encoding of the Hamiltonian $H$ and a projected unitary encoding of the stacked jump operator $B=\sum_{k=1}^m \lvert k\rangle\otimes L_k$, with normalization factors $α_H$ and $α_B$, respectively. For evolution time $t$, set $τ=(α_H+α_B^2)t$. The algorithm approximates the evolution channel to diamond-norm error $\varepsilon$ using $O\!\left(τ+\frac{\log(1/\varepsilon)}{\log\!\left(e+\log(1/\varepsilon)/τ\right)}\right)$ oracle queries, matching the query lower bound for Hamiltonian simulation. The number of additional one- and two-qubit gates is linear in the query complexity up to polylogarithmic factors. The query- and gate-complexity bounds extend to Lipschitz-continuous time-dependent Lindbladians under coherent time-indexed oracle access. Our construction uses a one-query transducer that implements a product of rational approximations to short-time evolution when supplied with a catalyst. We bound the error from omitting the catalyst by exploiting orthogonality between different sequences of Kraus labels. The gate implementation combines a compressed Kraus-label representation, which stores only the positions and values of the nonzero labels, with the rotation factorization of Chen et al.
