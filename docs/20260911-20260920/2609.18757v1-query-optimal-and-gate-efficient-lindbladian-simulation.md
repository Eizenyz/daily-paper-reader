## 摘要
我们给出一种用于 Lindbladian 模拟的量子算法：给定哈密顿量 H 的块编码，以及堆叠跳跃算符 B=Σ_{k=1}^m |k⟩⊗L_k 的投影酉编码，归一化因子分别为 α_H 和 α_B。对于演化时间 t，令 τ=(α_H+α_B^2)t。该算法使用 O(τ+log(1/ε)/log(e+log(1/ε)/τ)) 次 oracle 查询，将演化信道逼近到菱形范数误差 ε，达到哈密顿量模拟的查询下界。额外单量子比特门和双量子比特门的数量与查询复杂度呈线性关系，至多相差多对数因子。查询复杂度和门复杂度界可扩展到在相干时间索引 oracle 访问下的 Lipschitz 连续时变 Lindbladian。我们的构造使用一个单查询转换器，在提供催化剂时实现短时演化的有理逼近的乘积。我们通过利用不同 Kraus 标签序列之间的正交性，来界定省略催化剂所导致的误差。门实现结合了一种压缩的 Kraus 标签表示（仅存储非零标签的位置和值）与 Chen 等人的旋转分解。

## Abstract
We give a quantum algorithm for Lindbladian simulation given a block encoding of the Hamiltonian $H$ and a projected unitary encoding of the stacked jump operator $B=\sum_{k=1}^m \lvert k\rangle\otimes L_k$, with normalization factors $α_H$ and $α_B$, respectively. For evolution time $t$, set $τ=(α_H+α_B^2)t$. The algorithm approximates the evolution channel to diamond-norm error $\varepsilon$ using $O\!\left(τ+\frac{\log(1/\varepsilon)}{\log\!\left(e+\log(1/\varepsilon)/τ\right)}\right)$ oracle queries, matching the query lower bound for Hamiltonian simulation. The number of additional one- and two-qubit gates is linear in the query complexity up to polylogarithmic factors. The query- and gate-complexity bounds extend to Lipschitz-continuous time-dependent Lindbladians under coherent time-indexed oracle access. Our construction uses a one-query transducer that implements a product of rational approximations to short-time evolution when supplied with a catalyst. We bound the error from omitting the catalyst by exploiting orthogonality between different sequences of Kraus labels. The gate implementation combines a compressed Kraus-label representation, which stores only the positions and values of the nonzero labels, with the rotation factorization of Chen et al.

## 2. 方法论：核心思想与关键技术

### 2.1 输入模型与目标

- 假设可访问 H 的 Hermitian α_H-块编码 U_H，以及堆叠跳跃算符 B = Σₖ |k⟩_E ⊗ Lₖ 的投影酉编码 U_B（归一化因子 α_B，投影 P_L 到 H_L ⊗ H_S）。
- 查询算符打包为 Ω = U_H ⊕ U_B ⊕ U_B†，每次应用（或其受控版本）计为一次查询。
- 总归一化 α = α_H + α_B²，归一化时间 τ = αt；目标是实现信道 e^tL 的钻石范数误差 ε 逼近。

### 2.2 有理 CPTP 离散化（第 2 节）

- 单步 δ = t/J 用 CPTP 映射逼近：K = iH + ½B†B，R_δ = (I + δK/2)⁻¹，N_δ = (I − δK/2)R_δ，J_δ = √δ B R_δ。
- Stinespring 等距：W_δψ = |0⟩_E ⊗ N_δψ + J_δψ，其 Kraus 标签 0 对应 N_δ，k≥1 对应 √δ LₖR_δ。
- 误差界：当 αδ ≤ 1/2 时，‖Φ_δ − e^{δL}‖⋄ ≤ 10(αδ)²，故 J 步后 ‖Φ_δ^J − e^{tL}‖⋄ ≤ 10τ²/J（核心误差来源之一）。

### 2.3 单查询转换器（第 3–4 节）

- 采用 Belovs–Jeffery–Yolcu [BJY24] 的 transducer 框架，公共空间为 H_E ⊗ H_S，私有空间 H_priv = (H_AH⊗H_S) ⊕ (H_AB⊗H_E⊗H_S)^{⊕2}。
- 构造与 δ 相关的酉 G 与催化剂映射 γ，满足 **S_δ((|0⟩_E⊗ψ) ⊕ γψ) = W_δψ ⊕ γψ**，且 **γ†γ ⪯ αδI**。
  - 关键技巧：把目标变换写成 (I + iκ²H̄ + β²B̄†B̄) 形式的规范化算符，构造 M = (2P_u − I)·diag(1, −i, 1)（P_u 为沿 u = (1,κ,β)ᵀ 的投影），从而在无跳跃项与跳跃项之间精确分配角色。
  - 当 B=0 时退化为哈密顿量的 Cayley 变换转换器。
- 通过 transducer 的顺序复合（[BJY24, Prop. 9.9]）把 J 个局部转换器组合为全局 S，催化剂 Γ 为各步催化剂的直和，**Γ†Γ ⪯ τI**，且 S 只用一次查询。

### 2.4 免催化剂复用与误差恒等式（第 5 节）

- 复用电路把公共输入振幅均匀分配到 N 份相互正交的 H_J 副本，依次施加 S 并共享私有空间；得到 P_N 的投影酉编码。
- 核心恒等式：**W_J − P_N = S₀₁ g_N(S₁₁) Γ**，其中 g_N(ζ) = N⁻¹Σ_{ℓ=0}^{N−1} ζ^ℓ。

### 2.5 多项式加速与 LCU（第 6 节）

- 取 p(ζ) = ζ²(1+ζ²)，F_q(ζ) = (p(ζ)/2)^{2q}；利用 S₁₁(0)² = −投影 得 p(S₁₁(0)) = 0。
- 通过 Kraus 标签序列的**单调性与正交性**（附录 A）证明 **‖F_q(S₁₁)‖ ≤ (C₀τ/q)^q**（条件 q ≥ C₀τ，J ≥ 8q）。
- 用平滑多项式 g_{12q} 构造 Q_q = F_q·g_{12q} = Σ_{N=1}^{20q} λ_N g_N，满足 Σλ_N = 1、Σ|λ_N| = 2，从而 LCU 归一化为常数 2，只需 20q 个复用长度。
- 得到 WJ 的归一化-2 投影酉编码 V（至多 20q 次 S 调用），误差 ≤ √τ (C₀τ/q)^q。

### 2.6 幅度放大与参数选择（第 7 节）

- 使用 Cleve–Wang 的等距无关幅度放大（OAA），投影块为 (3/2)f − (1/2)f³，误差 ‖U_amp ι_in − ι_out W_J‖ ≤ 5η，对应信道误差 ≤ 10η，总计 ≤ 60q 次查询。
- 取 q = ⌈c(τ + L_ε/log(e + L_ε/τ))⌉（L_ε = log(20/ε)），J ≥ max{2τ, 8q, 20τ²/ε}；当 2τ ≤ ε 时恒等信道已足够。

### 2.7 门复杂度优化（第 9 节）

- 分解 G = R·G(0)，G(0) = E(I ⊕ D)（E 为 Kraus 标签交换，D 为私有空间相位/交换，R 为残余旋转）；重排因子后 E 全部右移、D 全部右移，得到 S = (R_{J−1}…R₀)(E_{J−1}…E₀)Q′。
- **压缩 Kraus 标签表示**：只存储 O(q) 个非零标签的位置与值（按位置递减排列），因为每次 S/S† 调用最多改变一个非零标签；配合 Algorithm 1 用受控交换实现直和形式的交换算子。
- 旋转部分利用 [CGJ+26, Lemma 10] 的旋转分解，把时间索引范围按 2 的幂区间划分，实现每个区间的 Rot(d^L)，使每次调用门数仅含 (log J)² 项。
- 最终把演化切成 n 段以控制 q² 项，得到门数 O((τ + log(1/ε)/log(e+log(1/ε)/τ))·[a + ℓ_ε(log(m+1) + ℓ_ε)])。

### 2.8 含时推广（第 8 节）

- 假设 H(s)、B(s) 一致有界且 L_s 关于 s 满足 Lipschitz 条件，在相干时间索引 oracle（Σ_j |j⟩⟨j|_T ⊗ U_{H,j} 等）下，分段使用常系数有理步；额外离散误差为 L_LT²/(2J)。
- 查询复杂度与时间无关情形相同（定理 8.1），门复杂度相应变为定理 9.1。
