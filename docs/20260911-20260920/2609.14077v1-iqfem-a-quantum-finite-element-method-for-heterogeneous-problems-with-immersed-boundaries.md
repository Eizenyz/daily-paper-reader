## 摘要
量子计算有望以比经典方法更有利的复杂度标度求解计算力学问题。为实现这一潜力，一种与量子兼容的有限元格式至关重要。我们提出了这样一种格式，用于在由浸入均匀笛卡尔网格离散的一般区域上求解具有空间变化系数的泊松问题。所得带状稀疏系统矩阵被编码为元素为多项式的对角矩阵及其与移位矩阵的乘积之和。矩阵之和通过酉算符线性组合（LCU）技术构造。所得块编码系统矩阵可使用多对数数量的基本门实现。对于浸入边界，块编码系统矩阵进一步用由0和1构成的对角指示矩阵进行处理。该指示矩阵由整数值水平集函数定义，该函数通过布尔集合运算由简单几何基元构成。所需的整数运算使用量子算术即时计算。所得块编码线性方程组使用量子奇异值变换（QSVT）求解。包括QSVT在内的总门数为 $O(N_{\text{tot}}^{2/d} \operatorname{polylog}(N_{\text{tot}}))$，其中 $d$ 是问题维度，$N_{\text{tot}}$ 是网格点数。在证实理论复杂度估计的数值算例中，对于浸入问题，解近似线性收敛；对于单连通区域，解二次收敛。

## Abstract
Quantum computing offers the potential to solve computational mechanics problems with a more favourable complexity scaling than classically possible. To realise this potential, a quantum-compatible formulation of the finite element method is essential. We present such a formulation for Poisson problems with spatially varying coefficients on general domains discretised by an immersed uniform Cartesian grid. The resulting banded sparse system matrices are encoded as the sum of diagonal matrices with polynomial entries and their products with shift matrices. The sum of the matrices is formed using the linear combination of unitaries (LCU) technique. The resulting block-encoded system matrix can be implemented using a polylogarithmic number of elementary gates. For immersed boundaries, the block-encoded system matrix is further processed using a diagonal indicator matrix with zeros and ones. The indicator matrix is defined in terms of an integer-valued level-set function composed of simple geometric primitives via Boolean set operations. The required integer operations are computed on the fly using quantum arithmetic. The resulting block-encoded linear system of equations is solved using quantum singular value transformation (QSVT). The overall gate count, including the QSVT, is $O(N_{\text{tot}}^{2/d} \operatorname{polylog}(N_{\text{tot}}))$, where $d$ is the problem dimension and $N_{\text{tot}}$ the number of grid points. In numerical examples that confirm the theoretical complexity estimates, the solutions converge approximately linearly for immersed problems and quadratically for simply connected domains.

# IQFEM 论文深度总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：量子线性系统求解算法（Harrow-Hassidim-Lloyd、Childs-Kothari-Somma、QSVT 等）在理论上对系统维度呈多对数（polylog）复杂度、对条件数呈多项式复杂度，相较经典有限元求解有望带来指数级加速。
- **核心瓶颈**：这类算法的复杂度估计通常以"查询 oracle 的次数"表述，隐含假设 oracle 本身可用 polylog 数量的基本门实现。然而，**非结构化有限元离散得到的系统矩阵难以高效块编码**——通用块编码方法（如 FABLE、Arcsin）门数随系统规模呈多项式（甚至二次）增长，抵消了量子优势。
- **已有方案的局限**：量子谱方法（quantum spectral methods）要求矩阵在特定基下呈对角或块对角结构，对**空间变系数（heterogeneous）**和**任意形状区域**一般不可行。
- **本文目标**：提出 **IQFEM**（Immersed Quantum Finite Element Method），在**结构化均匀笛卡尔网格 + 浸入边界（immersed/embedded/cut FEM）**框架下，为变系数泊松问题构造门数呈多对数增长的块编码，并用 QSVT 求解，从而打通"量子兼容的有限元格式"这一关键环节。

## 2. 方法论：核心思想与关键技术

### 2.1 总体思路
- 在 $(0,L)^d$ 上划分 $N+1$ 等分均匀网格，用线性基函数离散；每个单元内扩散系数 $\mu$ 视为常数（若 $\mu$ 为多项式则系统矩阵元素为网格指标的多项式，否则先经典多项式逼近）。
- 系统矩阵元素是**行指标（即网格点坐标）的多项式**，因此可分解为"**多项式元素的对角矩阵**"与"**移位矩阵（shift operator）**"的乘积之和。
- 用 **LCU（酉算符线性组合）** 将各分量相加，所得幺正电路即为系统矩阵的块编码。

### 2.2 系统矩阵分解
- **一维**：三对角矩阵 $A/\|A\|_{\max}$ 作用 = 主对角 + 上/下移位后乘对角矩阵，即 $\tilde\xi$、$\tilde\alpha$、$\tilde\beta$ 三个多项式对角矩阵分别作用于 $|v\rangle$、$S^+|v\rangle$、$S^-|v\rangle$；移位由 $U_{\text{add}}(\pm1)$（模 $2^n$ 加法，带进位/溢出位实现零填充）实现。
- **二维**：块三对角矩阵分解为 **1 个对角块 + 4 个非对角块**（$\tilde\xi,\tilde\alpha,\tilde\beta,\tilde\gamma,\tilde\delta$ 五个双变量多项式），移位算符为 $I\otimes S^\pm$、$S^\pm\otimes I$。
- **非周期边界**通过修改移位算符实现（截断而非循环移位）。

### 2.3 关键电路技术
- **多项式编码 $U_{\text{poly}}$**：单辅助比特 + $|k\rangle$ 寄存器，输出态幅度为 $\tilde f(k)$，余项幅度为 $\sqrt{1-\tilde f(k)^2}$，保证幺正性。
- **LCU 中的 W 态**：$U_{\text{prep}}$ 制备一维 $\frac{1}{\sqrt3}(|001\rangle+|010\rangle+|100\rangle)$、二维 $\frac{1}{\sqrt5}(\cdots)$ 的 unary（W）态。相比 Hadamard 均匀叠加态，**select 层每个受控门只需单控制**，显著减少 CNOT 数。
- **子归一化因子**：一维 $\sigma=3\|A\|_{\max}$，二维 $\sigma=5\|A\|_{\max}$，远小于 FABLE/Arcsin 的 $\sigma=N\|A\|_{\max}$，有利于后选择概率与 QSVT 多项式阶数。

### 2.4 浸入边界的处理
- **水平集函数**：采用**整数值**水平集 $\phi(k)$（允许后续扩展为定点数），由简单几何基元（半平面/楔形）经**构造实体几何（CSG）**的布尔运算（max、绝对值）组合，例如：
  - 一维：$\phi(k_0)=|k_0-c|-b$
  - 二维菱形孔：$\phi(k)=|k_0-c|+|k_1-c|-b$（符号曼哈顿距离）
  - 二维六边形孔：三个楔形的 max 组合
- **量子算术即时计算**：用 QFT 型量子算术（$U_{\text{add}}$ 量子-经典加法、$U_{\text{qadd}}$ 量子-量子加法、$U_{\text{abs}}$ 绝对值/借位）计算水平集与指示函数，避免高次多项式逼近带来的 Gibbs 振荡与门数爆炸；借助均匀叠加态可**一次性对所有网格点并行求值**，并须 uncompute 以保持可重复调用。
- **Dirichlet 边界**：指示矩阵 $D_\chi$（域内为 1、孔内为 0），系统矩阵 $A_D=D_\chi A D_\chi$；通过两个 $U_\chi$ 与 $U_A$ 串联实现块编码。
- **Neumann 边界**：$A_N=A_D-D_N\,(I\circ A)/(2d)$，其中 $D_N$ 非零元等于边界点落在孔内的最近邻个数（由计数子电路 $U^{\text{inc}}_{k_0\pm1},U^{\text{inc}}_{k_1\pm1}$ 统计），并用三个受控 $R_Y$ 门（角度 $\gamma_{1,2,3}=-2\sin^{-1}(c/4)$）缩放对角项，最后用 LCU 将修正项从 $A_D$ 中减去。

### 2.5 QSVT 求解
- 对 $1/x$ 在 $S_\lambda=[-1,-\lambda_{\min}]\cup[\lambda_{\min},1]$ 上用**奇次 Chebyshev 多项式**逼近正则化逆函数 $g(x)=\lambda_{\min}/(2x)$，用 **QSPPACK** 计算相位因子 $\{\phi_j\}$。
- 由 $U_A$、$U_A^\dagger$ 与投影控制的 Pauli-Z 旋转交替构成 QSVT 电路，得到 $p(A/\sigma)$，从而近似 $\frac{\lambda_{\min}\sigma}{2}A^{-1}$；零特征值（孔内网格点）对应的奇异值被自动抑制，无需特殊处理。
- 查询复杂度 $O(\kappa\log(\kappa/\epsilon))$；在 $\kappa\sim h^{-2}\sim N_{\text{tot}}^{2/d}$ 假设下，**总门数 $O(N_{\text{tot}}^{2/d}\,\mathrm{polylog}(N_{\text{tot}}))$**（一维二次、二维线性、三维次线性，未加预条件）。

## 6. 主要结论与发现

- **编码效率**：IQFEM 对变系数与浸入边界问题的系统矩阵块编码门数随网格点数呈**多对数增长**，显著优于 FABLE/Arcsin 的多项式增长；所需辅助比特数与多项式逼近阶数无关，只与求和/多项式编码有关（一维 5 个辅助位、二维 7 个辅助位量级）。
- **整体复杂度**：包括 QSVT 在内的总门数为 $O(N_{\text{tot}}^{2/d}\,\mathrm{polylog}(N_{\text{tot}}))$；**一维二次、二维线性、三维次线性**——即在不做预条件的情况下，整体门数仍随 $N$ 多项式增长，polylog 优势主要体现在编码阶段。
- **精度表现**：单连通区域问题可恢复**最优二次收敛**；浸入边界问题因阶梯状边界逼近只能达到**近似一阶（线性）收敛**，二维菱形孔与六边形孔均表现出误差集中于孔边界与尖角附近。
- **QSVT 行为**：最小非零奇异值随 $N^{-2}$ 下降，导致所需 Chebyshev 阶数 $\rho$ 随网格加密而显著增长（一维约二次、二维约线性），$\rho$ 即为块编码查询次数；即使 $\rho$ 达数千，QSVT 的幺正性保证了数值稳定性。
- **Neumann 情形代价更高**：由于需要 LCU 组合 $A_D$ 与对角修正项、并引入受控版本的块编码幺正，门数明显高于 Dirichlet 与纯非均质算例。

## 7. 优点

- **首次将 polylog 块编码推广到"变系数 + 任意形状域"**：突破了此前仅适用于常系数周期/结构化问题的限制。
- **分解思想简洁而通用**：把带状稀疏矩阵表示为"多项式对角矩阵 × 移位算符"之和，天然契合结构化网格的规则性，且易于扩展到三维及更高维。
- **水平集"即时计算"策略巧妙**：用 CSG + 二进制编码 + QFT 量子算术代替高次多项式逼近，避免了 Gibbs 振荡与门数爆炸，并可对所有网格点并行求值；配合 uncompute 保证可重复调用。
- **LCU 采用 W（unary）态**：使 select 层只需单控制门，显著降低 CNOT 数量，是工程上的实用优化。
- **子归一化因子小**（3 或 5 倍 $\|A\|_{\max}$，而非 $N$ 倍），有利于后选择成功率与 QSVT 阶数控制。
- **数值验证与理论标度一致**：门数-规模曲线、收敛率、$\rho$–$N$ 关系均与理论预测吻合，可信度较高。
